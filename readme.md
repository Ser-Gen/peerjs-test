# PeerKit

Peer-to-peer tools between two devices over [PeerJS](https://peerjs.com/). Open the site on one device, scan the QR code with the other, then send text and files directly between them.

Static files, no build step. For local development: `python3 -m http.server` and open <http://localhost:8000>. Phone features (camera, clipboard, wake lock) need HTTPS, so test on a phone through GitHub Pages.

See [PLAN.md](PLAN.md) for the roadmap.
